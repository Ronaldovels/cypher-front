## Regras de registro (resposta ao feedback da Sprint 3)

- Cada ata tem **no máximo 1 página** e registra **decisões do time**: quem decidiu, o que foi decidido, quem ficou responsável. Detalhe técnico fica em specs, PRs e commits, e a ata só aponta o link.
- Cada entregável é commitado **pela conta de quem o produziu**, via PR revisado por outra pessoa. A autoria no git é a evidência da divisão de trabalho.
- Toda data é absoluta e fica dentro da janela acima. Se a janela mudar, a mudança é registrada no Planning ou na Review com o motivo.
